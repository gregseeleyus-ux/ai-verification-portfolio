# book-recon

Status: PROTOTYPE

Reconstructs a book's useful content from public sources when you do not have the book. Gives a read, skim, or skip verdict first, then harvests the frameworks, heuristics, and data worth keeping.

**Use it:** When someone recommends a book and you want to know if it is worth your time, or want its tools without reading it.

**Depends on:** guardian-context (recommended)

**Install:** see docs/INSTALL.md. The skill itself is SKILL.md in this folder.
