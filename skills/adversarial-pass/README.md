# adversarial-pass

Status: BUILT

A structured red-team pass on a draft: classifies findings (Dangerous, Exploitable, Boring, Irrelevant), marks each claim as verified, inferred, extrapolated, or unsourced, and ends with an audit you can act on.

**Use it:** Before a proposal, brief, strategy, or plan goes to a decision-maker, or when you want a hard second read of another AI's output.

**Depends on:** guardian-context

**Install:** see docs/INSTALL.md. The skill itself is SKILL.md in this folder.
