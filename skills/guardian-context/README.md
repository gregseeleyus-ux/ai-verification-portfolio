# guardian-context

Status: BUILT

The shared standards every other skill in this repo loads first: evidence tiers and confidence tags, claim-level verification, a feasibility filter for decisions that depend on people, an adversarial pre-mortem, voice and formatting rules, and the standards for building new skills.

**Use it:** Load it whenever the work needs rigor. The other skills assume it is loaded.

**Depends on:** None. Everything else depends on it.

**References:** references/templates.md (output templates) and references/sector-vocab.md (sector vocabulary table).

**Install:** see docs/INSTALL.md. The skill itself is SKILL.md in this folder.
