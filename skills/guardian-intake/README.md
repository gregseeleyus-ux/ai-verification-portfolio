# guardian-intake

Status: DESIGNED

Triage for raw, ambiguous input (notes, emails, forwarded chains): classifies it, restates the real ask, names the decisions inside it, and recommends where it should go, with a paste-ready handoff.

**Use it:** When a pile of input arrives without a clear ask.

**Depends on:** guardian-context

**Note:** Works best with a routing map you write for your own projects; without one, every route is provisional.

**Install:** see docs/INSTALL.md. The skill itself is SKILL.md in this folder.
