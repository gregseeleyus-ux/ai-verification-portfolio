# decision-brief

Status: DESIGNED

Turns a real decision into a one-page brief: what is being decided and by when, the options priced (including doing nothing), and a mandatory verdict with confidence and the evidence that would change it.

**Use it:** When you are weighing a choice or circling a decision without landing it.

**Depends on:** guardian-context (recommended)

**Install:** see docs/INSTALL.md. The skill itself is SKILL.md in this folder.
