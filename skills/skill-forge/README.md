# skill-forge

Status: BUILT

Builds, tests, refactors, and retires skills, and keeps the promotion-gate record: a skill only moves up the BUILT / PROTOTYPE / DESIGNED / CONCEPT scale when real use shows it works.

**Use it:** When the work is about the skill catalog itself rather than a task.

**Depends on:** guardian-context (Sections 1 and 8)

**Note:** Uses templates/SKILLS-RECORD.template.md and, optionally, templates/SYSTEMS-INDEX.template.md.

**Install:** see docs/INSTALL.md. The skill itself is SKILL.md in this folder.
