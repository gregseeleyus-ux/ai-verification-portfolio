# Systems Index

Full inventory of your AI systems, organized by domain. Keep one current
working copy. When you replace it, rename the old one
"Archive (YYYY-MM-DD) - SYSTEMS.md" instead of deleting it, so the
archives document how the work evolved.

Status labels (guardian-context Section 1 maturity scale):
- BUILT: fully built and in use
- PROTOTYPE: partially built or run once
- DESIGNED: specified but not built
- CONCEPT: idea stage

Promotion requires a performance record (SKILLS-RECORD.md for packaged
skills). Classify down, not up.
