# Executive Brief Output Template

Status: DESIGNED. Generalized from an analysis workspace template; this form has not been used.

## What it is

A fixed shape for a brief written to a decision-maker. It leads with the bottom line (BLUF), frames the problem as Situation, Complication, Question, Answer (SCQA), and supports the answer as a Minto pyramid: one governing thought, a few key lines beneath it, and evidence beneath each key line. Every recommendation opens with one of three verbs, Accelerate, Pause, or Reframe, taken from strategic foresight practice, in which leaders classify their response to each major shift.

## When to use it

- Turning research, a workbook (templates/issues-solutions-workbook.template.md), or a foresight scan into a decision document for an executive, board, or client.
- Any brief where the reader must be able to act after reading the first paragraph.

## How to run it

1. Write the answer first. If you cannot state the governing thought in one or two sentences, the analysis is not done.
2. Build the SCQA frame. The Question is the one the reader actually faces; the Answer is the governing thought.
3. Group support into a few key lines. Each key line is a claim, not a topic label, and each rests on evidence below it.
4. Draw facts from the Verified tier of your ground truth reference (templates/ground-truth-reference.template.md). Tag each claim verified, inferred, or extrapolated.
5. Give each recommendation exactly one verb:
   - Accelerate: invest in or speed up something high-leverage.
   - Pause: stop or hold something failing or obsolete until a stated condition is met.
   - Reframe: keep the issue but change how it is understood, argued, or approached.
6. Do not force a verb. An item that does not earn one is parked and says so (for example Watch or Not now) with what would move it.
7. Review the action table on a set cadence (for example quarterly). Parked items move to a verb when their exposure grows.

## Output

One brief in this order: bottom line, SCQA, key lines with tagged evidence, action table, and evidence notes.
