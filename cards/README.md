# Knowledge Cards

A knowledge card is a short Markdown file with YAML frontmatter that states one working method, rule set, or framework. Cards are small on purpose: load one into an AI conversation to give it that method, cite it, and version it on its own. Method cards use the frontmatter shown in each file (title, category, version, status, origin). For findings cards (one finding or entity per card) use templates/knowledge-card-template.md; fuller output templates are in skills/guardian-context/references/templates.md.

These are the author's method cards, cleaned of anything tied to a specific employer, client, or person. Most were built in 2025, before the Claude skills in this repo.
