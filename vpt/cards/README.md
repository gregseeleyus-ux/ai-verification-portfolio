# VPT Role Cards

One file per role. Load a card into an AI conversation to give it that role's
focus and standards; load two to four and ask them to argue. See
vpt/README.md for how to run a session and vpt/templates/card-template.md
for making new cards.

Consent rule, no exceptions: cards inspired by real people are built only from
public material, generalized and anonymized. The goal is understanding how a
kind of person thinks, never imitating a specific named individual.
