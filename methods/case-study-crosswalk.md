# Case Study Crosswalk

Status: DESIGNED. Generalized from a working practice; this general form has not been used yet.

Adapted from a collaborator's practice: a recurring way of arguing, turned into a deliverable format.

## What it is

A way to argue for adopting a model that has already worked somewhere else. Each objection you expect gets answered by the same four-link chain: the objection, a counter-example jurisdiction where the model works anyway, the legal or governance mechanism that made it work there, and a translation of that mechanism to local conditions. The mechanism carries the argument, not the outcome.

## When to use it

- You are proposing a policy, infrastructure, program, or organizational model to decision-makers who will ask "where has this worked?"
- You can predict the objections (cost, legal authority, scale, incumbent opposition, operating risk).
- You have a set of reference cases, for example from a research report or a case-study file, and need to turn them into an argument rather than a survey.

Not for a general literature review, or for a single case that answers no particular objection.

## How to run it

1. **List the anticipated objections.** Write each one the way the decision-maker would say it. One objection per row.
2. **Pick a counter-example jurisdiction for each objection.** It should be a place where the model is operating even though that objection applied there too. Each reference case should be mapped to the specific objection it answers, not listed on its own.
3. **Name the enabling mechanism.** Give the specific legal authority, governance structure, or financing instrument that made the model work in that jurisdiction (for example a joint-powers agreement, a dedicated funding stream, a long-term offtake contract, or a public-private partnership structure).
4. **Translate to local conditions.** Name the local analog of that mechanism: an existing statute, entity, asset, or authority that could play the same role. If there is no local analog, say so in the row. Do not force a match.
5. **Assemble the crosswalk.** Keep the chain order fixed in every row: objection, counter-example, mechanism, translation.

## Output

A crosswalk table with one row per objection. You can use it as a section of a briefing memo or as an appendix to a deck.

## Template

```
Case Study Crosswalk: [model being proposed]
Audience: [decision-maker or body]
Reference case source: [report or case file]

| # | Anticipated objection | Counter-example jurisdiction | Enabling mechanism (legal or governance) | Local translation |
|---|-----------------------|------------------------------|------------------------------------------|-------------------|
| 1 | "[objection, in their words]" | [jurisdiction and model] | [authority, structure, or instrument that made it work] | [local analog, or "no local analog"] |
| 2 |                       |                              |                                          |                   |
| 3 |                       |                              |                                          |                   |
```
